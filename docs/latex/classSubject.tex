\doxysubsection{Detailed Description}
\doxylink{classSubject}{Subject} role of the \doxylink{classObserver}{Observer} pattern. 

Stores non-\/owning pointers to registered Observers. \doxylink{classSubject}{Subject} does not delete its observers on destruction — it only clears its registration list. \doxylink{classObserver}{Observer} object lifetime is managed by whatever owns it in the Composite tree instead, so a \doxylink{classSubject}{Subject} that is also a Composite-\/owned child is never deleted twice.
