\doxysubsection{Detailed Description}
Represents a demo kiosk within the event, capable of receiving notices and reporting its status. 

The \doxylink{classDemoKiosk}{Demo\+Kiosk} class inherits from \doxylink{classEventUnit}{Event\+Unit} and \doxylink{classObserver}{Observer}, allowing it to be part of the event\textquotesingle{}s unit structure, receive notifications about various events or changes in the system, and report its own status accordingly.
