\doxysubsection{Detailed Description}
Base class for all event notices pushed through the \doxylink{classObserver}{Observer} collaboration. 

A \doxylink{classNotice}{Notice} is \doxylink{classNexusCon}{Nexus\+Con}\textquotesingle{}s order/notice representation (see spec section 7, final bullet)\+: it carries the message and severity that get pushed to every observer\textquotesingle{}s update() call, rather than observers pulling state back from the \doxylink{classSubject}{Subject} (push model, Task 3.\+5).
