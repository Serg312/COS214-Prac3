\doxysubsection{Detailed Description}
Represents an expo floor within the event, capable of receiving notices, reporting its status, and managing child components. 

The \doxylink{classExpoFloor}{Expo\+Floor} class inherits from \doxylink{classEventGroup}{Event\+Group}, \doxylink{classObserver}{Observer}, and \doxylink{classSubject}{Subject}, allowing it to be part of the event\textquotesingle{}s group structure, receive notifications about various events or changes in the system, report its own status accordingly, and manage a list of observers.
