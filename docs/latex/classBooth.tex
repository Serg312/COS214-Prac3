\doxysubsection{Detailed Description}
Represents a booth within the event, capable of receiving notices and reporting its status. 

The \doxylink{classBooth}{Booth} class inherits from \doxylink{classEventUnit}{Event\+Unit} and \doxylink{classObserver}{Observer}, allowing it to be part of the event\textquotesingle{}s unit structure and to receive notifications about various events or changes in the system.
