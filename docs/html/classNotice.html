Detailed Description

Base class for all event notices pushed through the Observer collaboration.

A Notice is NexusCon's order/notice representation (see spec section 7, final bullet): it carries the message and severity that get pushed to every observer's update() call, rather than observers pulling state back from the Subject (push model, Task 3.5).
