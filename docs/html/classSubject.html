Detailed Description

Subject role of the Observer pattern.

Stores non-owning pointers to registered Observers. Subject does not delete its observers on destruction — it only clears its registration list. Observer object lifetime is managed by whatever owns it in the Composite tree instead, so a Subject that is also a Composite-owned child is never deleted twice.
